IMPORTANT LIMITATION
This environment cannot run the complete Streamlit application against live sources because Streamlit is not installed and outbound requests from the local test container are blocked. The tests above verify parsers and code paths with controlled fixtures. Actual availability from your PC/network and third-party agency websites must be confirmed after installation. The project intentionally distinguishes undated issuer summaries from dated CRA reports and does not invent ratings or rating dates.

INSTALL
1. Back up your existing project.
2. Extract this ZIP into your project folder (replace files when prompted).
3. Keep your existing .venv; it is not included.
4. Restart with: .venv\Scripts\activate
5. Run: python -m streamlit run app.py
6. Open Credit Rating and press "Refresh rating sources" once.
