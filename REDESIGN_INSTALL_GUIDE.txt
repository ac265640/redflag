INSTALL
1. Stop the current Streamlit process (Ctrl+C).
2. Back up the existing project folder.
3. Extract this ZIP to a new folder first, or merge its RedFlag_Intelligence folder into your project root.
4. Keep your existing .venv and any local .streamlit/secrets.toml file. Do not overwrite secrets with the example file.
5. Install/update dependencies only if needed: .venv\Scripts\python.exe -m pip install -r requirements.txt
6. Start using the existing project launcher, or:
   .venv\Scripts\python.exe -m streamlit run app.py

THEME

- Use the sidebar “Dark appearance” toggle for graphite + emerald dark mode.
- The toggle state is held in Streamlit session state for the active browser session.
