RED FLAG INTELLIGENCE — LIGHT THEME READABILITY FIX v3

Purpose
-------
This patch corrects the mixed-theme rendering visible in the supplied screenshots:
- Sidebar is now LIGHT (white) with dark readable navigation labels.
- Market News headlines use dark green readable links on white.
- Annual Report and Corporate Regulatory hero/panel cards use light surfaces.
- Forensic cards, badges, tabs and labels use light-theme colours.
- Plotly chart text and Company Overview chart labels use light/neutral colours.
- The Streamlit categorical chart palette uses institutional emerald/neutral tones.
- The final theme layer is injected AFTER page-local styles so embedded custom CSS
  cannot silently restore the old navy panels.

This is a focused replacement patch. It does NOT replace company data, secrets,
caches, financial models, source connectors, or the virtual environment.

INSTALL
-------
1. Stop Streamlit with Ctrl+C.
2. Make a backup of the current project folder.
3. Extract this ZIP into the EXISTING project root (the folder containing app.py).
4. Choose Replace for the included files. Preserve .streamlit/secrets.toml.
5. Restart from the project root:
   .venv\Scripts\python.exe -m streamlit run app.py
6. Hard refresh the browser with Ctrl+F5.
